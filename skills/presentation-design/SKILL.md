# Presentation Design

이 스킬은 기본 생성 경로의 필수 단계가 아니다. AI Slop 방지, 내러티브 아크,
주제 고유성, 정보 위계와 레이아웃 리듬은 `prepare_design_doc_draft`가 생성하는
DESIGN.md의 정식 계약이다.

사용자가 별도의 art direction 탐색을 요청한 경우에만 사용한다.

## 결과

DESIGN.md의 기존 네 영역을 편집할 수 있는 구체적 제안을 만든다:

- 전역 디자인 시스템: 사용자 브랜드와 발표 환경에 맞는 팔레트·타입 스케일
- 톤 & 방향: 이 발표만의 시각적 관점과 시그니처
- AI Slop 방지 원칙: 실제 제품·데이터·업무 artefact를 활용하는 구체적 기준
- 페이지별 요청: 기본 생성에서 의도적으로 벗어나야 하는 소수의 슬라이드

## 탐색 기준

- 사용자 브랜드 자산, 실제 제품 화면, 데이터, 코드, 장소와 대상 청중을 우선한다.
- 여러 방향을 제안할 때는 각 방향이 발표의 목적을 어떻게 강화하는지 설명한다.
- 기존 DESIGN.md guardrail을 복제하거나 별도의 공통 anti-pattern 목록을 만들지 않는다.
- 사용자가 선택한 방향만 DESIGN.md에 반영한다. 선택 전에는 슬라이드를 생성하지 않는다.
