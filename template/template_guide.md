## 3. 새 프레젠테이션 만들기

### 방법 A: 이 템플릿에서 새로 시작

1. 빈 슬라이드에 콘텐츠를 입력
2. 불필요한 슬라이드나 숨겨진 슬라이드 삭제
3. 슬라이드 추가: **Insert 탭 > New Slide 아래 화살표** 클릭 후 원하는 레이아웃 선택
4. 마지막에 **Thank You** 슬라이드로 마무리

### 방법 B: 기존 슬라이드 덱에 템플릿 적용

1. 이 템플릿의 왼쪽 패널에서 **모든 슬라이드를 선택하고 삭제** (Ctrl+A 후 Delete)
2. 기존 덱을 열고 **모든 슬라이드 선택** (Ctrl+A) 후 복사
3. 템플릿 파일의 빈 왼쪽 패널에서 우클릭 > **Use Destination Theme** 선택하여 붙여넣기
4. 각 슬라이드에 적절한 레이아웃 적용: **Home 탭 > Slides 섹션 > Layout**
5. 슬라이드 리셋: **Home 탭 > Slides 섹션 > Reset**

---

## 4. 마스터 슬라이드 편집

- **View > Master > Slide Master** 에서 편집
- 마스터 슬라이드는 Slide Master 보기의 맨 첫 번째 슬라이드
- 문서 제목, 페이지 번호 등을 이곳에서 편집하면 모든 슬라이드에 반영

## 6. 폰트 가이드

| 용도 | 폰트 | 스타일 |
|---|---|---|
| **제목/본문** | Amazon Ember Display Regular | Sentence case |
| **Eyebrow 텍스트** | Amazon Ember Mono Regular | ALL CAPS |
| **코드** | Lucida Console | - |

### 폰트 규칙

- 슬라이드 텍스트: **최소 20pt**
- 다이어그램 텍스트: **최소 12pt**
- 하이퍼링크가 아닌 텍스트에 밑줄 사용 금지
- 색상으로 강조할 경우 **볼드도 함께** 사용

---

## 7. 접근성 가이드라인

- 텍스트/배경 간 **대비율 최소 4.5:1** 유지
- 이미지, 차트에 **설명 대체 텍스트(alt text)** 추가
- **Review > Check Accessibility** 로 접근성 검사 실행
- 선 굵기 **최소 1.5pt** 사용

## 9. 주의사항

- 이 템플릿은 **글로벌 이벤트용이 아님** (글로벌 이벤트는 별도 템플릿 사용)

## 10. python-pptx로 프로그래밍 사용 시 참고

```python
from pptx import Presentation

# 템플릿 로드
prs = Presentation("./template.pptx")

# 레이아웃 선택 (인덱스로 접근)
layout = prs.slide_layouts[0]   # Title Side 1A
slide = prs.slides.add_slide(layout)

# Placeholder 접근
slide.placeholders[0].text = "제목"      # Title
slide.placeholders[1].text = "부제목"    # Subtitle
slide.placeholders[10].text = "EYEBROW"  # Eyebrow
slide.placeholders[11].text = "날짜"     # Date/Presenter
slide.placeholders[12].text = "추가 정보" # Extra info
```

### 자주 쓰는 레이아웃 인덱스 빠른 참조

| 용도 | 레이아웃 인덱스 | 주요 Placeholder idx |
|---|---|---|
| 표지 | `0` ~ `4` | 0(제목), 1(부제목), 10~12 |
| 아젠다 | `9` ~ `14` | 0(제목), 10(본문) |
| 섹션 구분 | `75`, `77`, `79` | 0(제목) |
| 제목+콘텐츠 | `21` | 0(제목), 1(콘텐츠) |
| 제목+불릿 | `22` | 0(제목), 1(콘텐츠) |
| 2열 비교 | `30` | 0(제목), 1/3(소제목), 2/4(콘텐츠) |
| 3열 | `40` | 0(제목), 1/3/10(소제목), 2/4/11(콘텐츠) |
| 인용문 | `71` | 0(인용문), 15(출처), 16(직함) |
| 코드 | `81` | 0(제목), 1(코드) |
| Thank You | `87` ~ `92` | 10~15(연락처 정보) |
| 빈 슬라이드 | `20` | 없음 |
