# 디자인 스펙 Validator

Date: 2026-02-26

## Status

Superseded by [ADR lint/0003](./0003-validator-to-lint.md)

## Context

디자인 스펙의 구조적 오류를 생성 이후에 검출하고 수정하는 검증 단계가 필요했다.

## Decision

이 결정은 후속 ADR에서 보고 중심 Lint 모델로 재정의됐으며, 현재 결정은
[lint/0003](./0003-validator-to-lint.md)을 따른다.

## Consequences

이 문서는 과거 결정의 인덱스만 유지하고 현재 동작을 중복 정의하지 않는다.
